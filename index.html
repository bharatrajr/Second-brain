One file in a "Waystation Backups" folder in your Drive, visible only to you (drive.file scope). Each sync pulls it, merges note-by-note with what's changed on this device, resolves what it can automatically, and pushes the result back — so this same file is what every device syncs against.
Normal sync never silently drops edits: if the same note changed on two devices before they synced, both versions are kept — one tagged conflict — so you can merge by hand. Force push/pull are one-way overrides for when you want one side to simply win.
